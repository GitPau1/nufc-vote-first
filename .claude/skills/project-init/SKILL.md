# 스킬: project-init

PRD와 디자인 시스템 폴더를 읽어 프로젝트 SSOT 파일 두 개를 생성한다.

---

## 트리거 조건

프로젝트 최초 실행 시 메인 에이전트가 호출한다.

---

## 입력

- PRD 파일 경로 (Markdown, 1개 이상)
- 디자인 시스템 폴더 경로
- 기술 스택 정보 (사용자가 대화로 제공)

---

## 출력

### `/vault/project.md`

```markdown
# 서비스 개요
## 목적
## 핵심 원칙

# 기술 스택
## 프론트엔드
## 백엔드
## DB / 인프라

# 디자인 시스템
## 원본 경로: /vault/design-system/
## 인덱스: /vault/design-system-index.md

# 기능 목록
## [ ] 기능명 — 미착수
```

### `/vault/design-system-index.md`

디자인 시스템 폴더를 스캔하여 생성:
- 사용 가능한 컴포넌트 목록 및 간략 설명
- 핵심 디자인 토큰 (색상, 타이포그래피, 간격 값)
- 컴포넌트별 원본 파일 경로 (필요 시 추가 조회용)

---

## 검증

생성 후 `spec-validator` 스킬로 `project.md` 필수 섹션 존재 여부 확인.
실패 시 1회 재시도, 이후 사용자에게 누락 항목 확인 요청.
