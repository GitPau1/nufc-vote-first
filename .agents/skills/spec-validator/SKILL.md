# 스킬: spec-validator

명세서 또는 초기화 파일의 필수 필드 존재 여부를 검증한다.

---

## 트리거 조건

| 시점 | 검증 대상 |
|------|----------|
| 기획 에이전트가 명세 초안 완성 후 | `/vault/specs/<feature>.md` |
| 프로젝트 초기화 완료 후 | `/vault/project.md` |
| 개발 에이전트 완료 확인 시 | `/vault/output/<feature>/` 파일 목록 |

---

## 검증 규칙

### 기능 명세서 (`/vault/specs/<feature>.md`)
필수 섹션:
- `## 화면 목적`
- `## 컴포넌트 목록`
- `## 기능 흐름 / 분기 조건`
- `## 엣지 케이스`
- `## API 엔드포인트`
- `## 시각적 선택지`

### 프로젝트 중심 파일 (`/vault/project.md`)
필수 섹션:
- `# 서비스 개요`
- `# 기술 스택`
- `# 디자인 시스템`
- `# 기능 목록`

---

## 출력

- 성공: `PASS` 반환
- 실패: 누락된 섹션 목록과 함께 `FAIL` 반환
