# ResultProgress

투표 결과 한 줄 — 사진/이니셜 + 이름 + 득표율 막대 + 퍼센트를 한 번에 보여준다. `ResultView`(투표 결과 화면)에서 쓴다.

<Canvas of={ResultProgressStories.Highlighted} />
<Controls of={ResultProgressStories.Highlighted} />

## 배경

원래 이름은 `Progress`였고 Radix 기반으로 만들어져 있었는데, 실사용처가 0건이었다. 실제 결과 막대는 `ResultView.tsx`가 이 컴포넌트를 쓰지 않고 직접 만든 `div` + `width%`로 따로 구현돼 있었다 — 같은 일을 하는 코드가 두 곳에 나뉜 상태였다. `ResultView`의 실제 마크업 그대로 `ResultProgress`로 이름을 바꿔 통합했다. `role="progressbar"`·`aria-valuenow` 등 접근성 속성은 이번에 새로 얻은 것이다(예전 직접 구현엔 없었다).

## Highlighted

1위(또는 강조할 옵션)는 `highlighted`로 브랜드 색을 쓴다. 나머지는 회색.
