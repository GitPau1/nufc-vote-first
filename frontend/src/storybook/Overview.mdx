# NUFC Vote 디자인시스템

Newcastle United 팬 투표 플랫폼의 디자인시스템이다. 한국어 · 모바일 퍼스트 · 라이트 테마 전용.

## 이 Storybook의 역할

**사용 규칙의 원본은 각 컴포넌트의 MDX 파일이다.** 값(색상 코드, px)은 코드에 있고, "언제 어떻게 쓰는가"는 MDX에 있다.

| 찾는 것 | 어디에 있는가 |
|---|---|
| 토큰의 실제 값 | `frontend/tailwind.config.ts`, `frontend/src/app/globals.css` |
| 언제 어떤 걸 쓰는가 | 이 Storybook의 각 MDX 페이지 |
| 무엇이 어느 문서에 있는가 | `frontend/src/storybook/DESIGN-SYSTEM.md` (라우팅 인덱스) |

## 카테고리

사이드바 분류는 원티드 Montage 체계를 따른다.

- **Foundations** — Color, Typography, Layout, Radius, Elevation, State, Motion
- **Actions** — 누르는 것 (Button, Chip)
- **Contents** — 보여주는 것 (Card, Avatar, Separator, Progress, ListGroup, PollCarouselCard)
- **Loading** — 기다리는 것 (Skeleton)
- **Navigations** — 이동하는 것 (AppHeader, BottomNav)
- **Presentation** — 덮는 것 (Sheet, BottomSheet)
- **Selection and Input** — 입력하는 것 (Radio, TextInput, RatingMatrix, FormSection)

## 설명을 쓰는 기준

모든 항목에 설명을 달지 않는다. **제약이나 판단이 있는 곳에만** 쓴다.

| 대상 | 설명을 쓰는가 |
|---|---|
| 이름만으로 자명한 슬롯 (root, label, title) | 안 쓴다 |
| 제약이 있는 슬롯 (상호배제, 조건부 사용, 접근성 경고) | 쓴다 |
| 이름이 곧 의미인 variant | 안 쓴다 |
| 선택에 판단이 필요한 variant (어느 게 CTA인가) | 쓴다 |
