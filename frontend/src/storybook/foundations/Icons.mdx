# Icons

**`lucide-react`만 쓴다.** stroke 기반 아이콘 세트고, 다른 아이콘 라이브러리를 섞지 않는다. `strokeWidth`는 항상 기본값(2)을 쓴다 — 실제 코드에 override가 0건이다.

## 크기 스케일

크기는 **3단계뿐이다.** 아래 표는 이미 코드에서 쓰이고 있던 값을 그대로 수렴시킨 것이다 — 새로 정한 숫자가 아니다.

셋 다 Tailwind 기본 스케일 값이라 커스텀 토큰이 아니다 — [Layout](?path=/docs/foundations-layout--docs)의 간격 스케일과 같은 근거로 코드 변경 없이 쓸 수 있다.

## 색

아이콘 전용 색 토큰은 없다. SVG가 `currentColor`를 쓰기 때문에 부모의 텍스트 색을 그대로 물려받는다 — 즉 아이콘 색은 [Color](?path=/docs/foundations-color--docs)의 텍스트 토큰(`text-foreground`/`text-muted-foreground`/`text-brand`/`text-white` 등)을 그대로 따르면 된다. 아이콘만을 위한 별도 색 규칙을 만들지 않는다.

## 아이콘만 있는 버튼 — `aria-label` 필수

텍스트 없이 아이콘 하나로만 이루어진 버튼(캐러셀 이전/다음, 인라인 확인/취소 등)은 스크린 리더가 읽을 이름이 없다. 아래 둘 중 하나로 접근 가능한 이름을 반드시 준다.

| 방법 | 예시 |
|---|---|
| `aria-label` | `<button aria-label="이전 선수"><ChevronLeft /></button>` |
| `sr-only` 텍스트 | `<span className="sr-only">닫기</span>` (Radix `Dialog.Close`처럼 컴포넌트가 이미 시각적으로 숨긴 텍스트를 함께 두는 경우) |

옆에 보이는 텍스트가 이미 있는 아이콘(예: "회원 탈퇴" 버튼의 `Trash2`)은 아이콘이 장식일 뿐이라 별도 라벨이 필요 없다.

이 규칙을 기준으로 실제 코드를 점검해 라벨이 빠져 있던 6곳(캐러셀 이전/다음 버튼, 닉네임 저장/취소 버튼, 댓글 수정 완료/취소 버튼)을 보완했다.

## 하지 말 것

- `lucide-react` 외의 아이콘 라이브러리를 새로 들이지 않는다.
- 크기를 위 3단계 밖의 값(`h-5 w-5`, `h-7 w-7` 등)으로 임의로 고르지 않는다. 정말 새 크기가 필요하면 먼저 논의한다.
- `strokeWidth`를 개별적으로 바꾸지 않는다 — 한 화면에 굵기가 다른 아이콘이 섞이면 통일감이 깨진다.
