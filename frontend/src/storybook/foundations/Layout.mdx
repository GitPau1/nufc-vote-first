# Layout

**모바일 퍼스트.** 375px를 기준으로 설계하고, 데스크탑에서는 셸을 늘리지 않고 컨테이너 폭만 바꾼다.

## 화면 기준폭

| 기준 | 값 | 용도 |
|---|---|---|
| Android minimum | 360px | 최소 지원 폭. 여기서 깨지면 안 된다 |
| iOS baseline | 375px | **설계 기준폭** |
| App shell max | 480px | 모바일 셸의 최대 폭 |

## 컨테이너 폭 토큰

데스크탑에서 화면 성격에 따라 세 가지로 갈린다. 이게 이 레이아웃의 핵심 결정이다.

| 토큰 | 값 | 언제 쓰는가 |
|---|---|---|
| `max-w-shell` | 480px | **모바일 전용 UI에만.** BottomNav, Bottom Sheet. 데스크탑에서도 확대하지 않는다 |
| `max-w-content` | 1140px | 데스크탑 목록 화면(홈, 투표 목록). 카드형 셸이 아닌 일반 웹 컨테이너 |
| `max-w-detail` | 680px | 데스크탑 투표 상세(캐러셀·결과·댓글). 읽기 편한 폭 |

목록은 넓게(`content`), 읽는 화면은 좁게(`detail`), 모바일 전용 UI는 고정(`shell`). 데스크탑에서 모든 걸 480px 셸에 가두지 않는다.

## 페이지 마진

| 값 | 용도 |
|---|---|
| 16px (`px-4`) | 일반 화면 좌우 기본 |
| 20px (`px-5`) | 그리드가 강조되는 화면, 넓은 호흡이 필요한 섹션 |
| 0 | 표지 이미지, 하단 고정 CTA, BottomNav — 화면 가장자리에 닿아야 하는 것만 |

기본은 16px다. 20px는 480px 셸 안에서 여백이 과해지는 화면에는 강제하지 않는다.

## 간격 스케일

기본은 4px 배수다. 일반 레이아웃 간격은 **여기서 먼저 고른다.**

`gap-1`(4) `gap-2`(8) `gap-3`(12) `gap-4`(16) `gap-5`(20) `gap-6`(24) `gap-8`(32) `gap-10`(40) `gap-12`(48).

| 값 | 용도 |
|---|---|
| 4px | 아이콘과 텍스트의 아주 작은 간격 |
| 8px | 작은 컨트롤 내부 |
| 12px | 리스트 아이템 내부 |
| 16px | 페이지 기본 마진, 카드 내부 padding |
| 20px | 모바일 컬럼 그리드 여유 간격 |
| 24px | 섹션 간격 |
| 32px · 40px | 큰 섹션 간격, 화면 단위 상하 여백 |
| 48px | 화면을 세로로 크게 가르는 여백(빈 상태 일러스트 위아래, 온보딩처럼 여백 자체가 콘텐츠인 화면) |

### 2px 배수 — 일반 간격이 아니라 시각적 보정용

4px 배수 사이에 **끼워 넣는 보정값**이다. 새 레이아웃을 짤 때 기본으로 고르는 값이 아니라, 4px 배수로 만들어보니 한쪽은 좁고 한쪽은 넓어서 어느 것도 맞지 않을 때만 예외적으로 쓴다. Tailwind 기본 스케일에 이미 있는 클래스라 토큰 추가 없이 바로 쓸 수 있다.

| 값 | 클래스 | 용도 |
|---|---|---|
| 2px | `gap-0.5` | 아이콘 광학 정렬, hairline 보정(기존 `1px`·`2px` 용도와 동일선상) |
| 6px | `gap-1.5` | 4px는 좁고 8px는 넓을 때 — 아이콘·작은 배지 사이 |
| 10px | `gap-2.5` | 8px는 좁고 12px는 넓을 때 — 작은 컨트롤 내부 |
| 14px | `gap-3.5` | 12px는 좁고 16px는 넓을 때 — 카드 padding 미세 조정 |

`1px`은 이 표와 별개로 border·hairline divider(선 자체)에만 쓴다 — 간격이 아니다.

## 모바일 그리드

기본 2컬럼, 컬럼 간격 16px(여유가 필요하면 20px). 480px 셸 안에서도 2컬럼을 유지한다.

3컬럼은 같은 구조의 요약 지표를 나란히 놓는 컴포넌트 내부에서만 허용한다.

## 하지 말 것

- 스케일 밖의 `gap-[13px]`, `px-[18px]`를 만들지 않는다.
- 컴포넌트 고유의 고정 치수(예: 헤더 높이 `h-[62px]`, 미디어 비율 `h-[252px]`)는 예외로 허용한다 — 이건 간격이 아니라 **컴포넌트 형상**이기 때문이다. 다만 그 값이 여러 곳에서 반복되기 시작하면 토큰으로 승격할지 논의한다.
