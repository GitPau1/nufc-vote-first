# BottomNav

모바일 전용 하단 탭바(투표·예측·역대 선수·메뉴). `position: fixed`라 이 문서에서는 프리뷰 영역 하단에 붙어 렌더된다 — 실제 화면과 같은 위치다.

## 5개 경로에서만 보인다

`/`, `/polls`, `/predictions`, `/players`, `/menu` 외의 경로에서는 아예 렌더되지 않는다(`return null`) — 투표 상세·선수 상세 같은 서브 화면에서는 뜨지 않는다.

데스크탑에서 `AppHeader`의 GNB로 대체되는 화면(위 5개 전부)은 `sm:hidden`으로 숨긴다 — 모바일 전용이라는 뜻이다.

## props가 없다

`BottomNav`는 `usePathname()`으로 직접 현재 경로를 읽는다 — 위 3개 스토리는 Storybook의 Next.js 라우터 mock(`parameters.nextjs.navigation.pathname`)으로 경로를 바꿔 보여준 것이다.
