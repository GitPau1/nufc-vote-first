## 안 맞는 것 — `text-white`

선택된 칸 텍스트가 `text-on-solid`가 아니라 `text-white` 리터럴이다. `bg-brand-solid` 위에 흰 텍스트를 올리는 다른 곳들(`primitives/button.tsx`의 `default` variant 등)은 전부 `text-on-solid`를 쓴다 — 이 컴포넌트만 옛날 방식이 남아있다. 값 자체는 같아서(둘 다 `#ffffff`) 화면엔 차이가 없지만, 토큰 이전 대상으로 남겨둔다.
