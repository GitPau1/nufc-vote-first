# TextInput

컴포넌트가 아니라 `globals.css`의 `.input-field` CSS 클래스다. 컴포넌트로 추출할 만큼 variant가 갈리지 않아서 CSS 클래스로 유지했다.

쓰는 곳은 9곳이지만 전부 polls 도메인 2개 파일이다 — `UserPollCreateForm` 8곳, `OverallRatingPollClient` 1곳(textarea). 그 밖의 텍스트 입력 8곳(`CommentsSection` textarea 2, `MyFeedbackForm` textarea, `OnboardingForm`, `MyPageClient` 인라인 편집, `PollPickerContent` 검색, `PlayersPageClient` 검색, `AdminRatingsForm` 숫자 입력)은 이 클래스를 쓰지 않고 각자 인라인 클래스를 조립하고 있다 — radius·패딩·타이포가 사용처마다 다르다.

<Canvas of={TextInputStories.Default} />

```css
.input-field {
  @apply w-full rounded-sm border border-neutral-weak bg-surface px-3 py-2 text-label-1-normal text-neutral outline-none focus:border-brand-solid;
}
```

## Textarea

<Canvas of={TextInputStories.Textarea} />

`resize-none`을 추가로 붙인다 — 기본은 리사이즈 가능이라 레이아웃이 깨질 수 있다.

## Disabled — 정의돼 있지 않다

<Canvas of={TextInputStories.Disabled} />

`.input-field`엔 `disabled:` 스타일이 없다 — 브라우저 기본 회색 처리에 맡기고 있다. `Button`·`Badge`의 `disabled:bg-disabled disabled:text-disabled` 패턴과 다르다. 입력 필드가 비활성화되는 실제 화면(수정 불가 필드 등)이 생기면 그때 맞춰 넣는다.
