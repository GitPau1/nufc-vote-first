# FormSection / Picker

`UserPollCreateForm.tsx`(투표 만들기 폼)에 5번 반복되는 섹션 셸과, 그 안에서 쓰는 선수 선택(picker) 하위 패턴이다. 전용 컴포넌트로 추출하지 않고 각 사용처에 클래스를 그대로 반복해서 쓰고 있다 — 여기 스토리는 그 반복되는 마크업을 그대로 옮긴 것이다(원본은 `UserPollCreateForm.tsx`의 비공개 내부 함수 `EmptySelection`·`PlayerSummary`).

## 섹션 셸

```
rounded-lg border border-neutral-weak bg-surface p-4 shadow-g200
```

첫 줄엔 항상 `text-label-2 font-bold` 라벨이 온다.
