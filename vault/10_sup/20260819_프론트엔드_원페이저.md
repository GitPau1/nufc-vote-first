# NUFC Fan Poll
투표 서비스 로딩 성능 개선으로 초기 이탈 완화

## 배경
NUFC Fan Poll은 뉴캐슬 유나이티드 팬을 위한 웹페이지로, 지금까지는 투표 기능만 제공해왔다. 투표만으로는 사용자 유입을 늘리는 데 한계가 있어 서비스 개편을 진행 중이며, 그 일환으로 로딩 성능을 먼저 개선한다.

## 문제 정의
- 사용자: 뉴캐슬 팬(1차), SNS·커뮤니티 축구 팬덤(2차)
- 상황: 프로덕션 실측 Lighthouse Performance 73점(FCP 1.9s, LCP 14.4s)로 로딩이 느려 D1 13.9% / D7 2.0%까지 리텐션 급락, 76%가 단일 방문 후 이탈
- 한계: 초기 렌더링 지연으로 투표의 체감 가치를 느끼기 전에 로딩 단계에서 이탈이 발생

## 범위
- Pretendard 폰트 셀프 호스팅 + 서브셋(`next/font/local`)
- LCP 이미지 `fetchpriority="high"` 적용
- 외부·Storage 썸네일 사이즈·캐시 정책 정합화(`cacheControl` 1년)
- 색상 대비 디자인 토큰 조정
- PC 화면 추가 예정

근거: `20260819_lighthouse_분석.md`, `20260819_lighthouse_분석_리전변경후.md`

## 완성 기준
- **검증 데이터**: 프로덕션(nufc-fan-poll.vercel.app) 실측 Lighthouse 리포트 + 2026년 6월 Mixpanel 실사용 리텐션·참여율 데이터
- **완료 판정**: 개선 후 동일 조건(모바일, 4x CPU 스로틀)에서 재측정한 Lighthouse 리포트로 베이스라인 대비 개선을 확인

## 안정성
- 폰트 로딩 실패/지연 → 셀프 호스팅 서브셋 폰트 + font-display 전략
- 느린 네트워크에서 빈 화면 노출 → 로딩 스켈레톤/상태 처리
- 이미지 로딩 실패 → 에러 상태 UI 처리

## 재현성
- 네트워크·기기 편차로 측정값 흔들림 → 측정 조건(모바일, 4x CPU 스로틀) 고정, 반복 측정 후 중앙값 사용
- 캐시 영향으로 재현 안 됨 → 시크릿 모드/캐시 초기화 후 측정

## 설계 판단
- Pretendard 폰트 셀프 호스팅 + 서브셋 — 외부 폰트 CDN 왕복 제거로 FCP/LCP 개선을 노림(예상치, 확정 아님)
