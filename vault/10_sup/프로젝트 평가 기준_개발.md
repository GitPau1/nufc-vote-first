## **개발 (세부 직군별 택1)**

백엔드 · 프론트엔드 · 모바일 · AI 엔지니어는 평가받는 축이 다릅니다. 본인 지향에 맞는 하나를 고르세요.

### **백엔드**

- **채용에서 보는 것**: API 설계, 데이터 모델링, 신뢰성(에러·재시도), 성능·확장성, 테스트, 관측성.
- **플래그십: AI 기능을 감싼 서비스급 API**
    - AI 처리(요약·분류·추출 등)를 감싼 REST API. 입력 검증 · 구조화된 에러 · 인증 · 요청 한도 · 캐시 · 요청 로깅 포함.
    - 난도 핵심: 부하 테스트로 p95 응답시간 · 처리량 · 에러율 측정, 테스트 커버리지, 실패 재시도.
    - 상위로 보이려면: 병목을 찾아 개선 전후 수치를 제시하고, 캐시·큐 등 확장 설계를 설명.
    - 산출물: 동작 API + API 명세 + 설계 문서 + 부하·성능 리포트.

### **프론트엔드**

- **채용에서 보는 것**: UI 구현력, 상태 관리, 성능(렌더링·번들), 접근성, 컴포넌트 설계, 사용 경험 디테일.
- **플래그십: AI 기능이 들어간 프로덕트 화면**
    - 실시간 응답(스트리밍) UI, 로딩 · 에러 · 빈 화면 상태 처리, 접근성, 반응형.
    - 난도 핵심: Lighthouse 성능·접근성 점수, 번들 크기, 첫 상호작용까지의 체감을 개선 전후로.
    - 상위로 보이려면: 컴포넌트 재사용 구조와 상태 관리 선택의 근거를 설명.
    - 산출물: 동작 웹앱 + 컴포넌트 문서 + 성능·접근성 리포트.
