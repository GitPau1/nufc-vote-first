# 반복 인라인 UI 컴포넌트화 — 시안 (승인 전 실행 금지)

> 목적: 2026-08-24 페이지 전수 점검에서 확인된 **반복 인라인 UI**의 컴포넌트화.
> 배치는 확정 기준(`primitives/` ↔ `composition/<도메인>/`) 안에서만 한다. 아래 **이름·API는 전부 "제안"**이며, 항목별로 승인받은 것만 실행한다.
> 선행 완료: D단계(미정의 토큰 5곳 수정·문서/스토리 재동기화)와 A단계(PollPickerModal 등록, 인덱스 정정)는 이미 반영됨.
>
> 실행 대원칙(재편 시안과 동일): 실행 중 계획에 명시되지 않은 해석·결정이 필요해지면 멈추고 사용자에게 확인한다.

## 1. 투표 상세 히어로 배너 → `composition/polls/PollDetailBanner.tsx` (이름 제안)

**근거(4곳 동일 구조):** `TypeAPollClient.tsx:86-113` · `OverallRatingPollClient.tsx:144-154` · `OverallRatingResultView.tsx:45-57` · `TypeBPollClient.tsx:98-123`. 유리 배지 클래스 문자열 6곳 동일, placehold.co 폴백 URL 4곳 동일.

```tsx
interface PollDetailBannerProps {
  coverUrl: string | null      // null이면 현행 공통 폴백 URL
  title: string
  badges: string[]             // 좌하단 유리 배지 라벨 (현행 1~2개)
}
```

- **범위 밖:** `ResultView.tsx:91-95`의 252px 커버는 구조·높이가 달라 포함하지 않는다(무리하게 합치면 variant 발명).
- **테스트:** `design-foundation.test.mjs:95-113`이 5개 파일에 `banner-text-overlay` 존재를 하드코딩 검사 → 새 컴포넌트 파일 기준으로 단정문 재작성.
- **스토리:** `contents/`에 등록 + 인덱스 행 추가.

## 2. predict 공유 조각 — 이름 발명 없음, 저비용

- **2a. `MatchLabel`을 `shared.tsx`로 이동 + export.** 이미 존재(`PredictionFlowClient.tsx:376-382`), 주석(:375)이 "예측/확인/완료/결과 화면이 같은 모양"이라고 공유를 명시하는데 export가 안 돼 3곳이 복제: `PredictionDone.tsx:103-105`(index 없는 변형)·`:123-125`, `PredictionResult.tsx:90-94`. index 생략·`mt-5` 부가 클래스는 props(`index?`, `className?`)로 흡수.
- **2b. `MatchupTeam`을 `shared.tsx`로 이동.** `PredictionDone.tsx:276-283` = `PredictionResult.tsx:416-423` 클래스 동일, `ConfirmTeam`(`PredictionFlowClient.tsx:406-413`)도 동일 → 1개로.
- **테스트 중립 근거:** 세 파일 모두 `design-foundation.test.mjs:193+`의 PREDICT_FILES 검사망 내부 이동.
- **범위 밖(2차):** 포지션 픽 카드 3종(`FlowClient:472`/`Done:254`/`Result:390`)은 인터랙티브/정적/배지 변형이 있어 통합 API가 커진다 — 이번 승인 범위에서 제외 제안. ※ 이 제외는 사용자 목표가 아니라 **내 리스크 회피 판단**이다. 포함을 원하시면 별도 API 시안을 만든다.

## 4. players 원형 사진 폴백 → 기존 `Avatar` 재사용 (이름 발명 없음)

## 5. "제목+설명" 페이지 헤더 → `primitives/page-heading.tsx` (이름 제안)

**근거(5곳):** `menu/page.tsx:14-19` · `admin/page.tsx:28-33` · `admin/ratings/page.tsx:64-71` · `my/feedback/page.tsx:33-38` · `polls/create/page.tsx:38`. `admin/ratings/page.tsx:66-67` 주석("admin/menu/폼 페이지가 전부 이 토큰을 쓴다")이 공유를 이미 명시.

## 6. 제출 버튼 pending 표기 통일 (컴포넌트 아님 — 컨벤션 통일)

**문서 근거 있음:** `Skeleton.mdx:63`이 "제출 버튼의 pending 표시(`Loader2 animate-spin`, 투표 클라이언트 3곳)"를 관례로 명시.

- 최소안(시각 변화 거의 없음): 말줄임표 문자를 U+2026(`…`)으로 통일 — `OverallRatingPollClient`(현 `...`), `UserPollCreateForm:330`, `MyFeedbackForm:46`, `OnboardingForm:49`.
- 확대안: 스피너 없는 4곳(`UserPollCreateForm`·`MyFeedbackForm`·`OnboardingForm`·`AdminRatingsForm`)에도 `Loader2` 추가 — 시각 변화가 생기므로 별도 승인 필요. ※ 최소안 우선 제안은 **내 리스크 회피 판단**임.
