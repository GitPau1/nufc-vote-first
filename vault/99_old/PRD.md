# PRD — Newcastle United Fan Poll

**버전:** 1.0  
**작성일:** 2026-05-27  
**상태:** MVP

---

## 1. Product Overview

뉴캐슬 유나이티드 팬들이 시즌 종료 후 선수·감독·시즌 전체에 대한 의견을 투표 형태로 남기고, 다른 팬들의 집단 의견과 비교할 수 있는 **시즌 종료형 팬 참여 플랫폼**.

자유 커뮤니티가 아닌 구조화된 투표 인터랙션을 통해 팬 감정을 집단 데이터로 만든다.

---

## 2. Problem Statement

시즌 종료 직후 축구 팬들은 선수 평가, 이적·방출 의견, 팀 운영 평가 등에 대한 강한 감정과 의견을 갖는다. 그러나 대부분의 반응은 SNS 댓글·커뮤니티 게시판에 단편적으로 흩어져:

- 팬 의견이 구조화되지 않고
- 다른 팬과 비교할 수 없으며
- 참여 자체가 휘발된다

---

## 3. Product Goals

뉴캐슬 팬들이 시즌 종료 후:

1. **빠르게** 의견을 표현하고
2. **다른 팬들과 비교**하며
3. **반복적으로** 여러 투표에 참여하도록

만드는 것을 목표로 한다.

---

## 4. Target Users

- **Primary:** 뉴캐슬 유나이티드 팬, 시즌 종료 후 선수 평가에 관심 있는 팬
- **Secondary:** SNS·커뮤니티 기반 축구 팬덤 사용자

---

## 5. Core Hypotheses

| 가설 | 내용 |
|------|------|
| **H1** | 팬들은 시즌 종료 직후 강한 의견 표현 욕구를 가진다 |
| **H2** | 긴 글 작성보다 빠른 투표 인터랙션이 더 낮은 참여 장벽을 가진다 |
| **H3** | 결과를 참여 이후 공개할 경우 투표 참여율이 증가한다 |
| **H4** | 팬들은 다른 팬 의견·댓글 공감·논쟁 가능성에서 더 강한 감정 반응을 보인다 |
| **H5** | 예정된 투표 공개는 재방문 동기를 만들 수 있다 |

---

## 6. Product Principles

1. 투표는 빠르지만 가볍지 않아야 한다 — 선택은 의미 있는 결정처럼 느껴져야 한다
2. 결과는 참여 이후 공개된다
3. 팬 의견은 집단 감정으로 확장된다
4. 댓글은 토론보다 감정 표현에 가깝다
5. 참여 마찰은 최소화하되 신뢰성은 유지한다
6. 예정 투표로 다음 논쟁에 대한 기대감을 만든다

## 8. MVP Scope

### In Scope

| 기능 | 설명 |
|------|------|
| 인증 | Google Social Login (Supabase Auth) |
| 투표 — Type A | 단일 선수 × 다수 평가 옵션 (버튼 선택) |
| 투표 — Type B | 단일 주제 × 다수 선수 (스와이프 캐러셀 선택) |
| 투표 참여 | 단일 선택, 제출 후 수정 불가, 확인 모달 |
| 결과 공개 | 투표 완료 후 % + 총 투표 수 공개, 내 선택 강조 |
| 댓글 | 투표 완료 후 작성 가능, 최대 500자, 좋아요 |
| 예정 투표 | blur preview + 제목 + 카운트다운 |
| 마이페이지 | 프로필, 참여 투표 목록, 로그아웃, 탈퇴 |
| 투표 목록 | 최신순, 무한 스크롤 |

### Out of Scope (MVP)

- 자유 게시글
- 유저 생성 투표
- 실시간 채팅 / DM
- 팔로우 시스템
- 알림 시스템
- 랭킹 시스템
- 댓글 스레드 / 대댓글
- 신고 / 블라인드
- 소셜 공유
- 추천 알고리즘
- 관리자 전용 UI (DB 직접 접근으로 대체)

## 9. User Flow

```
접속
  └─ 투표 목록 열람 (비로그인 가능)
       ├─ 예정 투표: blur + 제목 + 카운트다운 확인
       └─ 투표 카드 클릭
            ├─ [비로그인] 로그인 유도 모달 → Google 로그인 → 투표 페이지 복귀
            └─ [로그인] 투표 페이지
                 ├─ Type A: 평가 버튼 선택 → 제출
                 ├─ Type B: 선수 카드 스와이프 → 선택 → 제출
                 ├─ 확인 모달 ("수정 불가, 신중하게 선택해주세요")
                 └─ 결과 화면
                      ├─ % + 총 투표 수 + 내 선택 강조
                      └─ 댓글 작성 / 좋아요
                           └─ 다음 투표로 이동
```

## 10. Behavioral Design Intent

### Commitment Design
로그인 필수 + 수정 불가 + 결과 후공개 → "한 번의 선택"에 무게감 부여

### Emotional Loop
투표 자체보다 결과 비교·공감 댓글·반대 의견에서 감정 참여 확장

### Anticipation Loop
예정 투표 preview → 다음 논쟁 기대감 → 재방문 이유 생성
