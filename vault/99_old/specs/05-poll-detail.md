# 05 — 투표 상세 페이지 (/polls/[id])

## 공통 레이아웃 구조

```
┌─────────────────────────────┐
│  [표지 이미지 150px]         │  ← 콘텐츠와 함께 스크롤됨 (fixed 아님)
│   ↳ 하단 그라데이션 오버레이 │
│   ↳ 투표 제목 (이미지 위)    │
│                             │  ← [◀ 돌아가기] 플로팅 버튼 (이미지 좌상단)
├─────────────────────────────┤
│  콘텐츠 영역 (스크롤)        │
│  · 유형뱃지 + 마감뱃지 + 참여자수
│  · 투표 설명                │
│  · 선택 UI (Type A / B)     │
│  · 선수 정보 (Type A만)      │
└─────────────────────────────┘
│  [투표하기] ← 하단 고정      │  ← border-radius: 0, 전체 너비
└─────────────────────────────┘
```

### 표지 이미지
- 높이 150px, `object-fit: cover`, 콘텐츠와 함께 스크롤
- 이미지 위 그라데이션: `linear-gradient(to bottom, transparent 15%, rgba(0,0,0,.55) 60%, rgba(0,0,0,.9) 100%)`
- 투표 제목: 이미지 하단에 흰색 텍스트로 오버레이

### 뒤로가기 버튼
- 위치: 표지 이미지 좌상단 (position: absolute, top: 16px, left: 16px)
- 스타일: 플로팅 pill 버튼 (backdrop-filter blur, 반투명 배경)
- "◀ 돌아가기" 텍스트 포함

### 제출 버튼
- 위치: 화면 최하단 고정 (position: absolute, bottom: 0)
- `border-radius: 0`, 전체 너비 (LDSG action-button-full-bleed)
- 선택 전: disabled 상태 (회색)
- 선택 후: Primary 색 활성화

## Type A — 단일 선수 · 다수 평가 (evaluation)

### 미참여 UI

```
[표지 이미지 — "이사크를 재계약해야 할까요?"]
 ──────────────────────────────────────
  [평가] [D-7 마감]   1,247명 참여

  이번 시즌 21골 11어시스트로 팀 최다 득점...

  (○) 재계약          ← radio-button, 선택 전
  (○) 보류
  (○) 방출

  ── 선수 정보 ──
  [아바타] 알렉산더 이사크
           공격수 · #14 · 스웨덴

 [투표하기 — 하단 고정, disabled]
```

- 옵션 버튼: LDSG radio-button 스타일 (왼쪽 원형 인디케이터 + 라벨)
- 선택 시: 인디케이터 안에 dot 표시, 버튼 배경 primary-dim
- **선수 정보 카드**: 콘텐츠 영역 하단에 참고용으로 표시. 아바타(44px 원형) + 이름 + 포지션/등번호/국적

## Type B — 단일 주제 · 다수 선수 (selection)

### 미참여 UI

```
[표지 이미지 — "2024-25 시즌 MVP는?"]
 ──────────────────────────────────────
  [선택]  5명 후보  [D-14 마감]

  이번 시즌 가장 인상적이었던 선수를 선택해주세요.

  [작은카드] [중앙카드(크게+강조)] [작은카드]
      ●  ○  ○  ○  ○   ← dot 인디케이터

  ✓ 선택: 알렉산더 이사크   ← 선택 확인 영역

 [투표하기 — 하단 고정]
```

- 캐러셀: Framer Motion 또는 embla-carousel
- **가운데 카드 = 현재 선택** → scale(1), 테두리 primary 색 + 그림자 강조
- 양옆 카드: scale(0.87), opacity 낮춤. 2칸 이상 벗어난 카드: opacity 0.45
- 카드 클릭 또는 좌우 스와이프로 선택 변경
- 초기 로드 시 첫 번째 선수가 선택 상태
- 카드 내용: 선수 사진, 이름, 포지션·등번호
- 하단 dot 인디케이터: 활성 dot은 primary 색 + pill 형태로 확장
- 선택 확인 영역: `✓ 선택: [선수 이름]` — primary-dim 배경, 5px radius

## 확인 모달 (공통 — Bottom Sheet)

```
   ─────   ← handle
  이 선택으로 투표하시겠어요?
  제출 후에는 변경할 수 없습니다

  ┌─────────────────────────┐
  │ (●) 내 선택             │
  │     재계약               │
  └─────────────────────────┘

  [취소]          [최종 제출]
```

- 하단에서 슬라이드업하는 Bottom Sheet (border-radius 12px top)
- 내 선택 요약: radio 인디케이터 + 선택 옵션명 표시
- 버튼 배치: 취소(outlined) 좌측, 최종 제출(contained) 우측 (LDSG: 우선순위 높은 쪽 오른쪽)
- "최종 제출" → `votes` 테이블 INSERT → 결과 화면으로 이동
- 중복 투표: DB UNIQUE 제약으로 차단 → 409 에러 → "이미 참여한 투표입니다" 토스트

## 결과 화면 (투표 후 / 재방문)

### 결과 계산 방식
- **실시간 계산**: 화면 진입 시 DB에서 `votes` 집계 → 퍼센트 계산
- 새로고침 시 최신 데이터 반영
- 별도 캐싱 없음 (MVP)

### 레이아웃

```
[뒤로가기]  이사크를 재계약해야 할까요?  [✓ 완료]

┌─────────────────────────────┐
│  최다 득표          (primary 배경)
│  재계약                 62%  │
│  ✓ 내 선택  총 1,248명 참여  │
└─────────────────────────────┘

┌─────────────────────────────┐
│  전체 집계                   │
│  재계약  [내 선택] ████  62% │ ← primary 색
│  보류              ███   25% │ ← 회색
│  방출              ██    13% │ ← 연한 빨강
└─────────────────────────────┘

── 댓글 N개 ──
[댓글 입력창]
[댓글 목록]
```

- **최다 득표 카드**: primary 배경, 옵션명 + 퍼센트 크게 표시. 내 선택이면 "✓ 내 선택" 뱃지
- **전체 집계 카드**: 가로 막대 + 퍼센트. 내 선택 항목은 primary 색 막대 + "내 선택" 뱃지
- 미참여자가 마감된 투표 접근 시에도 결과 열람 가능 (내 선택 강조 없음)

- 미참여자도 결과 열람 가능

## 에러 처리

| 상황 | 처리 |
|------|------|
| 이미 투표한 사용자 접근 | 투표 UI 대신 결과 화면 바로 표시 |
| 마감된 투표 접근 | 결과 열람 가능, 투표 버튼 없음 |
| 투표 제출 실패 (네트워크) | 에러 토스트 + "다시 시도해주세요" |
| 중복 투표 시도 (비정상 접근) | "이미 참여한 투표입니다" 토스트 |
| 비로그인 제출 시도 | 로그인 유도 모달 (→ 02-auth.md) |
| 존재하지 않는 poll id | 404 → `/` 리다이렉트 |
