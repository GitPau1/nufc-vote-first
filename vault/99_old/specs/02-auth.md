# 02 — 인증

## 방식
Google OAuth via Supabase Auth. 세션은 Supabase가 쿠키 기반으로 관리.

## 접근 권한

| 기능 | 비로그인 | 로그인 |
|------|---------|--------|
| 투표 목록 열람 | ✅ | ✅ |
| 예정 투표 preview | ✅ | ✅ |
| 투표 참여 | ❌ | ✅ |
| 댓글 작성 | ❌ | ✅ (투표 완료 후) |
| 댓글 좋아요 | ❌ | ✅ |
| 마이페이지 | ❌ | ✅ |

## 로그인 유도 흐름

1. 비로그인 상태에서 투표 제출 버튼 클릭
2. 로그인 유도 모달: "투표하려면 로그인이 필요합니다" + Google 로그인 버튼
3. 로그인 완료 후 동일 투표 페이지로 자동 복귀

마이페이지 직접 접근 시: `/` 로 리다이렉트.

## 헤더 상태

- 비로그인: 우측 상단 "로그인" 버튼
- 로그인: 우측 상단 구글 아바타 → 클릭 시 `/my` 이동
