# 04 — 투표 목록 페이지 (/)

최종 업데이트: 2026-09-04 (투표 정리 프로젝트, TEA-25/26/27/29 반영 — 코드 기준으로 갱신)

## 데이터 페칭
- `polls` 테이블 `created_at DESC` 정렬
- 페이지당 10개, 무한 스크롤
- `status`는 `'active' | 'closed'` 두 값만 존재한다 — 예정 투표(scheduled) 기능은 TEA-25(2026-09)로 완전 제거됨. `polls.scheduled_at` 컬럼은 DB에 남아 있으나 코드가 읽지 않는다.
- 화면 탭은 "전체 / 진행중 / 종료" 3개(`PollListClient.tsx`의 `PollTab`). "예정" 탭 없음.

## 투표 카드 레이아웃 (모바일 기본, `PollFeedCard`)

```
┌──────────┬──────────────────────────┐
│  사진    │  상태뱃지 (썸네일 좌상단)  │
│ 14:11    │  투표 제목                │
│  w-28    │                          │
│          │  N명 참여      작성일     │
└──────────┴──────────────────────────┘
```

- 썸네일: `w-28` 폭, 종횡비 `14:11`, `object-fit: cover`. 종료 상태는 `grayscale` 처리.
- 유형 뱃지(평가/선택 구분) 없음 — `PollType` 통합(TEA-26, 2026-09)으로 타입 개념 자체가 없어짐.
- 부제 없음 — 제목만 한 줄로 표시(`line-clamp-2`).
- 하단 메타 줄: 참여자 수(`vote_count`)와 작성일.

## 데스크탑 그리드 카드 (`PollGridCard`, `variant="vertical"`)

- 썸네일이 카드 폭 전체를 채우고 높이만 고정(`h-[168px]`), 정보는 아래.
- 제목 아래 부제 줄이 있다 — `poll.description`이 있으면 그 값을, 없으면 선택지 라벨 미리보기(`getOptionPreview`: 최대 3개를 " · "로 이어붙이고 나머지는 "외 N개")를 보여준다. 이 줄은 옛 스펙의 "N명의 후보" 고정 문구가 아니라 실제 콘텐츠 기반이다.
- 모바일 기본 카드(`PollFeedCard`)와 달리 이 그리드 변형만 부제를 표시한다.

## 상태 뱃지

- 종료(`status === 'closed'`): "종료됨"(중립 톤)
- 진행중: 마감까지 남은 시간(`D-N` 또는 마감 임박) — 1일 이하로 남으면 긴급(destructive) 톤, 그 외 기본 톤.

**결과 비율(%)은 카드에 표시하지 않는다** — 투표 완료 후 상세 페이지에서만 공개(불변 제약).
