# 08 — 댓글 시스템

## 작성 조건
- 로그인 상태
- 해당 투표에 참여 완료 (`votes` 테이블에 `poll_id + user_id` 레코드 존재)

미투표 사용자가 작성 시도 시: "투표 후 댓글을 작성할 수 있습니다" 안내.

## 작성 UI
- `textarea`: placeholder "이 투표에 대한 생각을 남겨보세요"
- 글자 수 카운터: `{현재}/500`
- 500자 초과 시 제출 버튼 `disabled`

## 댓글 목록
- 정렬: 좋아요 수 내림차순 (동률 시 최신순)
- 각 항목: 아바타, 닉네임, 작성 시간, 내용, 좋아요 버튼 + 숫자
- 대댓글 없음 / dislike 없음 / 신고 없음

## 좋아요
- 로그인 사용자만 가능
- `comment_likes` INSERT / DELETE 토글
- 중복 좋아요: DB UNIQUE 제약으로 차단
- 좋아요 수는 숫자로 표시
