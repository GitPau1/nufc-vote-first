# intent — 승부예측 결과 개편

작성: 2026-09-01 · 작성자: Fable(오케스트레이터), 사용자와의 브레인스토밍 세션 기록
승인권자: 사용자 (프로덕트 디자이너)

## 문제 (사용자가 직접 짚은 것)

현재 예측 결과 페이지(`frontend/src/components/composition/predict/PredictionResult.tsx`)가 최선이라는 확신이 없다. 구체적으로:

1. **정보 우선순위가 뒤집혀 있다** — 사용자가 결과 페이지를 여는 순간 가장 먼저 알고 싶은 건 "내 예측이 맞았는지"(통쾌함)인데, 현재 화면은 등수·점수 히어로가 최상단이다.
2. **모바일 토글 분리가 걸린다** — "내 예측 / 전체 결과" 세그먼트로 랭킹이 숨겨져 발견성이 낮고 흐름이 끊긴다.
3. **카드 안 정보 밀도** — 경기 예측 + 선수 픽이 한 카드에 길게 늘어져 한눈에 안 들어온다.

## 목표

결과 페이지를 "판정 퍼스트" 단일 스크롤로 재구성한다. 맞음/틀림 판정이 헤드라인, 등수는 피날레로.

## 확정된 화면 구성 (사용자 승인, v9 시안 기준)

블록 순서 (모바일·데스크탑 동일 구성, 토글 제거):

1. **판정 헤드라인** (다크 카드, `spotlight-glow-brand-strong`) — 단일 경기: "스코어 정확히 적중!" / 더블 매치위크: "2경기 중 1경기 적중!" / 미참여: 안내 문구
2. **경기별 비교 카드** — 헤더(제목 + 점수 badge), 크레스트 행, "내 예측"/"실제 결과" 2행 비교 테이블
3. **내 선수 픽** — 헤더(제목 + 합산 점수 badge). 데스크탑: 포지션 카드 3장 + 각 카드 아래 "포지션 평점 TOP3" 아코디언. 모바일: 가로 행 리스트(기존 PickResultRow 패턴 — 사진 48px·포지션·이름·평점 배지·점수), 행 탭으로 TOP3 펼침
4. **피날레** (다크 카드 하나에 통합) — 크게 "이번 주 순위 1위 / N명" → 스트립(경기예측·선수픽·총점) → 주차 랭킹 테이블(순위·예측·선수픽·종합 열, 내 줄 하이라이트) → 희미한 "더보기" 버튼
5. **공유 버튼** — 페이지 맨 하단

세부 결정:
- 경기 예측·선수 픽 헤더의 점수는 **같은 badge 형태**로 통일, "적중" 같은 단어 없이 "+N점"만
- 내 예측 행에 점수 텍스트를 넣지 않는다 (badge 한 곳에만)
- 총점 카운트업 애니메이션(기존 `useCountUp` 재사용) 후 순위 노출이 피날레의 감정 보상
- 픽 TOP3 아코디언 모션은 기존 `accordion-down 0.2s` 토큰 사용 (신규 값 금지)

## 상태별 처리 (사용자 확정)

- **미참여 주차**: 안내 문구 + 실제 경기 결과 카드 + 랭킹 (판정·피날레 등수만 빠짐). 랭킹 공개 정책은 기존 유지 (참여 무관 공개 — PredictionResult.tsx 주석 명시)
- **랭킹 집계 중**: 피날레는 총점 카운트업까지, 등수 자리에 "등수 집계 중"
- **경기 시작 전**: 현행 "아직 시작하지 않은 경기예요" 카드 유지

## 근거 미확인 (구현 전 반드시 확인)

- **포지션별 평점 TOP3**: 모든 후보 선수의 경기 평점 데이터가 필요한데, 현재 확인된 건 내가 픽한 선수의 평점뿐(`scored.picks[position].rating`). 전체 선수 평점을 조회할 수 있는지(테이블/뷰/RLS) 미확인 → **별도 이슈로 격리** (사용자 확정)
- 랭킹 "더보기" 기본 노출 인원 수(N) 미정 — 기존 `WeekRankCard`의 capped(10명) 로직 재사용 가능
- 다크 면 위 파란 강조 숫자(blue-400 직접 참조)는 semantic 토큰 부재 — 치환/신규 토큰/컴포넌트 예외 중 미정

## 이슈 분할 (사용자 확정: 프로젝트 + 이슈 분할)

1. 결과 화면 재구성 — 판정 헤드라인·비교 테이블·픽 재배치·피날레+랭킹 통합·더보기·공유 하단 (전부 같은 파일 중심이라 한 이슈, 순차)
2. 포지션별 평점 TOP3 — 데이터 근거 확인부터 (리스크 격리)

## 시안

- `시안-v9.html` (이 폴더) — 실제 디자인 토큰 값으로 만든 고충실도 목업, 데스크탑(720px)+모바일(375px), TOP3/픽 아코디언 동작 포함
- 참고한 레퍼런스 이미지 2장은 사용자 제공 (레이아웃·정보 위계만 채택, 색·타이포는 토큰으로 치환)
