참고로 짚어둘 것: 상단 헤딩 "5주차 제출 완료"는 이번에 손대지 않았습니다 — 세 분류가 섞인 허브에서는 "일부는 아직 안 냈는데 완료라고 하는 게 맞나" 싶은 지점이라, 바꿀지 여부는 이번 3개 확인 질문 범위 밖이라 판단해 그대로 뒀습니다(제 임의 변경 아님 — 필요하면 알려주세요, 별도 확인 대상으로 추가하겠습니다).

3. 수정 진입 상태

완료 허브에서 울브스전 카드의 "수정" 링크를 눌러 들어간 상태(design-brief §9 질문3 확정안 B — 경기 하나만, 그 경기 값만). 기존 제출값(2–1, 트리피어·루이스 마일리·이사크)이 채워진 채로 시작합니다.

3-1. 스코어 입력 단계 (기존 값 채움)

화면 카피 자체는 최초 제출 때와 동일합니다 — "수정 중"이라는 사실은 새 배지가 아니라 스코어에 이미 값이 들어있다는 것 하나로 전달합니다(design-brief·feature-spec 어디에도 별도 "수정 모드" 표시 요구가 없어 새 패턴을 만들지 않았습니다).
