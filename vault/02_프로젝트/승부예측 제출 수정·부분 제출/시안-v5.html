3. 더블 매치위크 — 매치 탭을 독립 컨테이너로 분리

탭을 Card 안쪽 푸터에서 완전히 빼서, Card와 StickyActionBar 사이에 놓이는 새 독립 컨테이너로 만들었습니다. 이 컨테이너는 데스크탑에선 카드 바로 아래 여백에 자연스럽게 나타나고(다른 형제 요소가 없던 자리), 모바일에선 카드 다음·화면 하단 고정 버튼 바 앞에 놓입니다 — DOM 순서상 하나의 동일한 위치(</Card> 바로 다음, <StickyActionBar> 바로 전)에 두면 두 화면 크기 요구사항이 동시에 만족됩니다(모바일 StickyActionBar는 position: fixed라 문서 흐름에서 차지하는 자리가 없기 때문). 카드 안쪽 툰 카운터·확인 안내 문구 자리는 전혀 건드리지 않았습니다.

정확한 배치 — 클래스·위치

  • DOM 위치: <Card>...</Card> 다음, <StickyActionBar> 이전(형제 요소로 새로 추가) — PredictionFlowClient.tsx의 최상위 리턴 블록(:458-528) 기준으로는 </Card>와 <StickyActionBar ...> 사이에 삽입.
  • 컨테이너 클래스: mt-3 flex gap-2 rounded-lg border border-neutral-weak bg-surface p-3 shadow-g200 — Card 프리미티브와 같은 표면 규칙(둥근 모서리·테두리·그림자)을 그대로 재사용한 독립된 작은 카드로, 화면에서 "이것도 하나의 뚜렷한 UI 영역"으로 읽히게 했습니다.
  • 버튼 내부 레이아웃 변경: 기존(v4) 가로 배치(아이콘+텍스트 나란히) 대신 flex flex-col items-center gap-1.5로 세로 스택 — 크레스트가 위, 구단명이 아래. 색·상태 클래스는 그대로 Button variant에서 가져왔습니다(활성 bg-brand-solid text-on-solid shadow-w200, 비활성 border-neutral-weak bg-transparent text-neutral) — 구조만 세로로 바뀌었을 뿐 색 시스템은 안 바꿨습니다.
  • 간격: 카드와 탭 컨테이너 사이 mt-3(12px) — 기존 코드가 쓰는 space-4 스케일과 일치.
