3. 더블 매치위크 — 매치 탭 색상 3단계 (참고 이미지 반영)

찾은 색 토큰 — 프로젝트 실사용 근거

참고 이미지의 "진행중 = 옅은 파란 채움 + 파란 글씨"는 bg-brand-weak text-brand 조합인데, 이건 프로젝트에서 이미 여러 곳에 쓰이는 조합입니다(Badge default variant, ToonCost 2툰 티어, radio.tsx·PlayerPick.tsx·PollPicker.tsx의 "선택됨" 상태 등). "안 함 = 회색 채움"은 bg-neutral-weak과 bg-disabled 둘 다 같은 값 (--p-neutral-200, #e9e9ea)이라 색만 봐서는 구분이 안 되지만, 의미로 쓰인 선례를 찾았습니다 — components/primitives/result-progress.tsx:43가 정확히 같은 이분법을 씁니다: highlighted ? "bg-brand-weak" : "bg-disabled"(막대 강조 여부), 텍스트도 highlighted ? "text-brand" : "text-neutral-muted"(:67, :76)로 우리 탭과 1:1 대응합니다. 그래서 "안 함"엔 bg-neutral-weak이 아니라 bg-disabled를 썼습니다.

이번 변경 — v5 대비

  • 3색 체계: 완료=흰 카드+테두리, 진행중=파란 채움(테두리 없음), 안 함=회색 채움(테두리 없음) — 참고 이미지 그대로. 테두리 유무를 다르게 둔 채 폭이 흔들리지 않도록 셋 다 border 1px는 유지하고 완료만 border-neutral-weak, 나머지 둘은 border-transparent로 처리했습니다.
  • 체크 배지 제거 — v5에 있던 우상단 체크 배지를 뺐습니다. 상태는 이제 색으로만 구분합니다(참고 이미지 지시 그대로).
  • 바깥 테두리 박스 제거 — v5의 TAB_CONTAINER(rounded-lg border ... shadow-g200 p-3)를 없앴습니다. 개별 탭 카드만 flex gap-2로 나열해 Card와 StickyActionBar 사이(v5와 같은 DOM 위치)에 바로 놓습니다 — 참고 이미지 2장이 보여준 "테두리 없이 바로 나열" 그대로.
  • 크레스트 모양: 참고 이미지가 "정사각형에 가까운 둥근 모서리 아이콘"을 보여줘, 이 목업에서는 자리표시자를 rounded-md 정사각형 박스로 바꿨습니다(기존엔 원형 rounded-pill이었음) — 실제 앱에서 TeamBadge는 로고 이미지를 그대로 쓰고 원형을 강제하지 않으니(폴백만 원형), 실제 로고 형태에 따라 최종 모양은 달라질 수 있습니다. 이 판단은 참고 이미지 재현 목적의 추정이라 확정 사항은 아닙니다.
  • 크레스트 위·구단명 아래 세로 배치, 데스크톱/모바일 둘 다, 선수 픽 단계 ToonCounter와 안 겹치는 것은 v5에서 이미 맞았던 부분이라 그대로 유지했습니다.
