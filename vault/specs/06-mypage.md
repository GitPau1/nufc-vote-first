# 06 — 마이페이지 (/my)

## 접근 권한
로그인 필수. 미로그인 접근 시 `/` 로 리다이렉트.

## 레이아웃

```
┌─────────────────────────┐
│  [아바타]               │
│  이름                   │
│  이메일                 │
│                         │
│  ─── 참여한 투표 ───     │
│                         │
│  [투표 제목]            │  ← 클릭 시 /polls/[id] (결과 화면)
│  내 선택: 재계약         │
│  2026.05.20             │
│                         │
│  [투표 제목]            │
│  내 선택: 이세르 이사크  │
│  2026.05.18             │
│                         │
│  [로그아웃]             │
│  [회원 탈퇴]            │
└─────────────────────────┘
```

## 참여한 투표 목록
- `votes` 테이블에서 `user_id = 현재 사용자` 조회
- `created_at DESC` 정렬
- 각 항목: 투표 제목, 내가 선택한 옵션 label, 참여 날짜
- 클릭 시 `/polls/[id]` 이동 (결과 화면이 바로 표시됨)

## 탈퇴 처리

1. "회원 탈퇴" 클릭
2. 확인 모달: "탈퇴 시 계정 정보가 삭제됩니다. 기존 투표 데이터는 익명으로 유지됩니다."
3. 확인 시: `users.deleted_at = now()` 업데이트 (소프트 딜리트)
4. Supabase Auth 세션 삭제 → `/` 리다이렉트
5. `votes`, `comments` 데이터는 익명 상태로 유지 (삭제 안 함)
