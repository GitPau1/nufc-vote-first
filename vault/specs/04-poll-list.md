# 04 — 투표 목록 페이지 (/)

## 데이터 페칭
- `polls` 테이블 `created_at DESC` 정렬
- 페이지당 10개, 무한 스크롤
- `status = 'active'` 와 `status = 'scheduled'` 함께 표시
- `status = 'closed'` 는 목록 하단 표시

## 투표 카드 레이아웃

```
┌──────────┬──────────────────────────┐
│          │  [유형뱃지] [마감뱃지]    │
│  사진    │  투표 제목                │
│  88×104  │  부제 (선수명·포지션 등)  │
│          │                          │
│          │  N명 참여                │
└──────────┴──────────────────────────┘
```

- 좌측: 썸네일 이미지 88×104px, `object-fit: cover`
- 우측: 뱃지 → 제목 → 부제 → 참여자 수 순 세로 배치

## 투표 카드 표시 항목

| 항목 | Type A (evaluation) | Type B (selection) |
|------|--------------------|--------------------|
| 대표 이미지 | polls.player_id 선수 사진 | 첫 번째 옵션 선수 사진 |
| 투표 제목 | polls.title | polls.title |
| 부제 | 선수 포지션·등번호 | "N명의 후보" |
| 유형 뱃지 | "평가" (주황) | "선택" (초록) |
| 마감 뱃지 | D-N (빨강) | 동일 |
| 참여자 수 | votes count | 동일 |
| 상태 뱃지 | 없음(활성) / "투표 종료"(마감) | 동일 |

**결과 비율(%)은 카드에 표시하지 않음** — 투표 완료 후 상세 페이지에서만 공개.

## 예정 투표 카드

- `status = 'scheduled'` 카드 전체에 blur 효과 (CSS `backdrop-filter: blur(8px)`)
- 표시: 잠금 아이콘 + 투표 제목 + 카운트다운 타이머
- 클릭 불가 (`pointer-events: none`)
- 타이머: 1일 이상 → "D-N" / 1일 미만 → "HH:MM:SS"

## 헤더

- 좌측: 서비스 로고
- 우측: 로그인 상태에 따라 구글 아바타(→ `/my`) 또는 "로그인" 버튼
