# Feature Brief: 서비스 확장 방향

## 왜
리텐션이 낮고("리텐션 낮음 - 투표"), 투표 자체가 가진 가치에 한계가 있다는 문제의식("투표가 가진 한계점 극복: 투표가 가치가 있는가?")에서 서비스 확장 방향을 논의함.

## 무엇
검토 중인 옵션 (아직 미확정):

1. 현재 서비스는 그대로 두고 프론트/백엔드 영역 분리, AWS로 이전
2. 게임 기능 추가 — [38-0](https://38-0.app/game) 스타일
3. 게임 기능 추가 — [fantasy](https://fantasy.premierleague.com/en/) 스타일 (경기력을 수치화해서 선수 구성 시 점수를 뽑아 경쟁)
4. 승부예측 — 기존 투표에서 한 depth 더 들어가는, 투표 종류가 하나 추가되는 형태 (참고: [fotmob predict](https://predict.fotmob.com/ko/1000086))
5. 포인트 시스템 — 승부예측/WAU 등에 포인트를 높은 비중으로 부여, 포인트를 게임과 연계해 활용
6. AI를 이용한 투표 자동화 — 특정 기간 동안의 새로운 소식/뉴스 중 특정 기준에 맞는 것만 선별해 투표 형식으로 변환한 뒤, 사람이 컨펌 후 업로드

랭킹은 게임 기능(특히 38-0)과 연계하는 방향으로 언급됨.

## 어떻게 (기술 방향)
회의록에 옵션별 구체적 기술 방향은 명시되어 있지 않음. 방향 확정 후 필요한 기술 결정은 별도 ADR로 분리.

## 디자인 방향
회의록에 명시 없음. 믹스패널 구성(관리자용)이 언급되었으나 이번 옵션들과의 관계는 불명확 — 다음 회의에서 확인 필요.

## 범위 밖
옵션이 아직 확정되지 않아 해당 없음.

## 완료 기준
다음 회의에서 방향성 확정 ("향후 방향성 확정"으로 회의록에 명시).
