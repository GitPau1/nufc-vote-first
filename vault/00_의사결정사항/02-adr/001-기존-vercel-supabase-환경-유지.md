# 001: 기존 프론트/백엔드 환경 유지

## Status
Accepted

## Context
서비스 확장 방향 논의(2026-08-18) 중 검토 옵션 1로 "현재 서비스는 그대로 두고 프론트/백엔드 영역 분리, AWS로 이전"이 올라와 있었다.
이후 Vercel에서 리전 변경이 가능한 것으로 확인되어, AWS 이전을 통해 얻으려던 부분을 기존 환경에서도 해소할 수 있는 상황이 되었다.

## Decision
프론트엔드·백엔드는 **기존 환경(Vercel + Supabase) 그대로 진행**한다. 영역 분리 및 AWS 이전은 진행하지 않는다.

## Consequences
- 인프라 이전 작업이 빠지므로 8월 24일 목표 일정을 UI 개편·기능 정의에 집중해서 쓸 수 있다.
- Vercel 리전 변경으로 대응 가능한 범위 안에서만 배포 환경을 조정하게 된다.
- 재검토 지점: 게임/포인트 등 확장 기능의 부하나 요구사항이 Vercel + Supabase 조합의 한계를 넘길 경우 이 결정을 다시 본다.
- 이전 대비 트레이드오프(비용, 운영 편의 등)에 대한 구체적 비교는 회의록에 남아 있지 않음 — 필요하면 다음 회의에서 확인.
